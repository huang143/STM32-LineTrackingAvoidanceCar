# 参数调试说明

本文档用于调试“巡线 + 避障”小车，重点是梯形避障动作的各个参数。

STM32 侧参数集中在：

```text
代码/BALANCE/CONTROL/control.h
```

OpenMV 侧参数在：

```text
openmv/main.py
```

修改后需要重新编译并下载到 STM32。建议每次只改一类参数，连续测试 3~5 次，并记录现象。

## 1. 先看懂 OLED 状态

避障过程中 OLED 会显示当前执行到第几步，以及障碍物分档：

```text
AVD:1 PIVOT   第 1 步：向绕行方向转出角度
AVD:1 EXIT    第 1B 步：沿斜向离开，形成梯形第一条腰
AVD:2 ALIGN   第 2 步：回正，车头与轨道平行
AVD:3 PASS    第 3 步：平行通过障碍物
AVD:4 BACK    第 4 步：向轨道方向转回角度
AVD:5 FIND    第 5 步：画弧找线（兜底）
```

`G:L/M/S` 表示 OpenMV 把当前障碍物分为大/中/小档：

```text
G:L  大障碍
G:M  中障碍
G:S  小障碍
```

先确认是哪一步结束、是哪一档障碍，再改对应参数，避免改错地方。

## 2. 触发距离与安全距离

| 参数 | 当前值 | 作用 | 调整建议 |
|---|---|---|---|
| `AVOID_START_DISTANCE_CM` | 35 | 距离小于该值且摄像头连续确认后开始绕障 | 绕障太早调小，太晚调大 |
| `AVOID_STOP_HOLD_MS` | 250 | 确认绕障后先停车等待的时间 | 停车后抖动/不稳定时可适当调大 |
| `AVOID_CONFIRM_COUNT` | 2 | 超声波+摄像头连续确认次数 | 误触发多就调大，反应慢就调小 |
| `ULTRASONIC_SLOW_DISTANCE_CM` | 30 | 进入慢速区距离 | 接近障碍时冲击大就调大 |
| `ULTRASONIC_STOP_DISTANCE_CM` | 18 | 安全停车底线 | 停车太晚调大，太早调小 |
| `ULTRASONIC_CLEAR_DISTANCE_CM` | 25 | 解除停车状态的滞回距离 | 停车后反复启停就调大 |

超声波参数在 `代码/Hardware/ULTRASONIC/ultrasonic.h`。

## 3. 梯形避障的阶段与参数

梯形动作可以理解为两条“腰”：

```text
第一条腰：PIVOT 转角 + EXIT 前进距离
第二条腰：BACK 转角 + BACK_EXIT 前进距离
```

### 3.1 转角参数

| 参数 | 当前值 | 作用 |
|---|---|---|
| `AVOID_LARGE_TURN_TARGET` | 150 | 大障碍的转出/回正/转回角度目标（编码器差值） |
| `AVOID_MID_TURN_TARGET` | 130 | 中障碍的角度目标 |
| `AVOID_SMALL_TURN_TARGET` | 110 | 小障碍的角度目标 |
| `AVOID_TURN_TIMEOUT_MS` | 1500 | 每次转向的最长保护时间 |

角度值越大，车转得越多。角度不够就调大对应档位的 `AVOID_xxx_TURN_TARGET`，转太多就调小。

### 3.2 第一条腰：斜向离开距离

| 参数 | 当前值 | 作用 |
|---|---|---|
| `AVOID_LARGE_EXIT_ENCODER_TARGET` | 820 | 大障碍沿斜向离开的编码器距离 |
| `AVOID_MID_EXIT_ENCODER_TARGET` | 710 | 中障碍的离开距离 |
| `AVOID_SMALL_EXIT_ENCODER_TARGET` | 600 | 小障碍的离开距离 |
| `AVOID_LEFT_EXIT_SCALE_X100` | 90 | 左绕时离开距离缩放，90 表示 90% |
| `AVOID_RIGHT_EXIT_SCALE_X100` | 100 | 右绕时离开距离缩放 |

离开距离不够会蹭到障碍，调大；离开太远会离轨道太远、回线困难，调小。

### 3.3 平行通过距离

| 参数 | 当前值 | 作用 |
|---|---|---|
| `AVOID_LARGE_PASS_MS` | 1300 | 大障碍平行直行通过时间 |
| `AVOID_MID_PASS_MS` | 1130 | 中障碍平行直行通过时间 |
| `AVOID_SMALL_PASS_MS` | 950 | 小障碍平行直行通过时间 |
| `AVOID_LEFT_PASS_SCALE_X100` | 100 | 左绕时通过时间缩放 |
| `AVOID_RIGHT_PASS_SCALE_X100` | 100 | 右绕时通过时间缩放 |

还没完全越过障碍就转回，调大；已经越过还在走，调小。

### 3.4 第二条腰：回到轨道的角度和距离

这是最近重点调试的部分。第四步现在与第一条腰对称：

```text
先按 BACK 转角目标转回轨道方向
再沿斜向走 BACK_EXIT 编码器距离
```

| 参数 | 当前值 | 作用 |
|---|---|---|
| `AVOID_LARGE_BACK_EXIT_ENCODER_TARGET` | 820 | 大障碍回线前进距离 |
| `AVOID_MID_BACK_EXIT_ENCODER_TARGET` | 710 | 中障碍回线前进距离 |
| `AVOID_SMALL_BACK_EXIT_ENCODER_TARGET` | 600 | 小障碍回线前进距离 |
| `AVOID_LEFT_BACK_EXIT_SCALE_X100` | 90 | 左绕时回线距离缩放 |
| `AVOID_RIGHT_BACK_EXIT_SCALE_X100` | 100 | 右绕时回线距离缩放 |
| `AVOID_BACK_EXIT_TIMEOUT_MS` | 2000 | 回线前进的最长保护时间 |

调整原则：

- 车还没到轨道就结束：调大对应档位的 `AVOID_xxx_BACK_EXIT_ENCODER_TARGET`；
- 车冲过轨道或绕过头：调小；
- 只调左绕：优先改 `AVOID_LEFT_BACK_EXIT_SCALE_X100`，当前是 90，可以先试 100~120；
- 只调右绕：改 `AVOID_RIGHT_BACK_EXIT_SCALE_X100`；
- 距离够但角度不对：改 `AVOID_LEFT/RIGHT_BACK_TURN_SCALE_X100`，当前左绕为 115、右绕为 100。

### 3.5 画弧找线兜底

| 参数 | 当前值 | 作用 |
|---|---|---|
| `AVOID_REJOIN_OUTER_PWM` | 3000 | 画弧时外侧轮 PWM |
| `AVOID_REJOIN_INNER_PWM` | 2200 | 画弧时内侧轮 PWM |
| `AVOID_REJOIN_MIN_TIME_MS` | 250 | 画弧开始后的最短执行时间 |
| `AVOID_RIGHT_RETURN_TIMEOUT_MS` | 1800 | 右绕后最长找线时间 |
| `AVOID_LEFT_RETURN_TIMEOUT_MS` | 2500 | 左绕后最长找线时间 |
| `AVOID_LINE_HOLD_COUNT` | 2 | 连续多少次看到黑线算找到线 |

找不到线就增大对应方向的 `RETURN_TIMEOUT_MS`，或增大内外轮 PWM 差让弧更明显；总是冲过线则减小。

## 4. 左右不对称调整

左右电机、轮胎、传感器安装不可能是完全对称的，所以代码里左右绕障分开调：

| 参数 | 当前值 | 作用 |
|---|---|---|
| `AVOID_LEFT_PIVOT_TURN_SCALE_X100` | 100 | 左绕转出角度缩放 |
| `AVOID_LEFT_ALIGN_TURN_SCALE_X100` | 100 | 左绕回正角度缩放 |
| `AVOID_LEFT_BACK_TURN_SCALE_X100` | 115 | 左绕转回轨道角度缩放 |
| `AVOID_LEFT_EXIT_SCALE_X100` | 90 | 左绕第一条腰距离缩放 |
| `AVOID_LEFT_BACK_EXIT_SCALE_X100` | 90 | 左绕第二条腰距离缩放 |
| `AVOID_LEFT_RETURN_TIMEOUT_MS` | 2500 | 左绕找线超时 |
| `AVOID_RIGHT_PWM_SCALE_X100` | 85 | 右轮整体动力缩放，避免左右绕不对称 |

左右分别调时，只动左侧或右侧的 `SCALE_X100`，不要动基础 `TURN_TARGET` / `EXIT_ENCODER_TARGET` / `BACK_EXIT_ENCODER_TARGET`，这样另一侧不会受影响。

## 5. 常见现象排查表

| 现象 | 优先调整 | 调整方向 |
|---|---|---|
| 还没到轨道，回线就结束 | `AVOID_xxx_BACK_EXIT_ENCODER_TARGET` | 调大 |
| 回线冲过轨道、绕过头 | `AVOID_xxx_BACK_EXIT_ENCODER_TARGET` | 调小 |
| 左绕回不到轨道 | `AVOID_LEFT_BACK_EXIT_SCALE_X100` | 90 -> 100/110/120 |
| 左绕冲过轨道 | `AVOID_LEFT_BACK_EXIT_SCALE_X100` | 90 -> 85/80 |
| 右绕回不到轨道 | `AVOID_RIGHT_BACK_EXIT_SCALE_X100` | 100 -> 110/120 |
| 离开障碍不够，会蹭到 | `AVOID_xxx_EXIT_ENCODER_TARGET` | 调大 |
| 离开轨道太远，回线困难 | `AVOID_xxx_EXIT_ENCODER_TARGET` | 调小 |
| 还没越过障碍就转回 | `AVOID_xxx_PASS_MS` | 调大 |
| 越过障碍后还在直行 | `AVOID_xxx_PASS_MS` | 调小 |
| 画弧找线一直找不到 | `AVOID_LEFT/RIGHT_RETURN_TIMEOUT_MS` | 调大 |
| 画弧找线总是冲过头 | `AVOID_LEFT/RIGHT_RETURN_TIMEOUT_MS` | 调小 |
| 转回角度不够 | `AVOID_LEFT/RIGHT_BACK_TURN_SCALE_X100` | 调大 |
| 转回角度太大 | `AVOID_LEFT/RIGHT_BACK_TURN_SCALE_X100` | 调小 |

## 6. OpenMV 识别参数

如果障碍识别不稳定，先调 `openmv/main.py`，不要动 STM32 动作参数：

| 参数 | 作用 |
|---|---|
| `BLACK_THRESHOLDS` | 黑色/暗色阈值，影响黑线和暗色障碍识别 |
| `ORANGE_THRESHOLDS` | 橙色/彩色障碍阈值 |
| `OBSTACLE_BANDS` | 上方障碍检测 ROI，按摄像头安装角度调整 |
| `OBSTACLE_WIDTH_RATIO_X10` | 暗色区域宽度与正常黑线的比例阈值 |

误检多就收紧阈值，漏检就放宽阈值；每次只改一个参数，并在 OpenMV IDE 里直接观察画面验证。

## 7. 调试记录模板

```text
日期：
障碍大小（G:L/M/S）：
绕行方向（左/右）：
执行的最后阶段（OLED）：
当前参数值：
现象：
修改的参数：
修改后的现象：
```

按模板记录后，即使中间隔了很久，也能快速定位是哪一类参数导致的偏差。
